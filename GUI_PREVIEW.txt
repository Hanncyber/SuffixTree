================================================================================
                             VISUAL ELEMENTS
================================================================================

NODES:
  ┌───┐     Regular node (Blue circle with black outline)
  │ R │     Root or internal node
  └───┘

  ┌───┐     Active node (Red circle - currently being processed)
  │ * │     
  └───┘

  ┌───┐     Leaf node (Blue circle with suffix index)
  │ 0 │     Number shows which suffix this represents
  └───┘

EDGES:
  [b$...]   Black lines with substring labels
  │         Labels show the text between start and end indices
  │         Long labels are truncated with "..."

STATUS INDICATORS:
  [PAUSED]  Red text - animation is paused (press SPACE to play)
  [PLAYING] Green text - animation is running automatically

ACTIVE POINT INFO:
  Shows the current state of Ukkonen's algorithm:
  - Which node is active (root or internal)
  - Which edge is being followed (shown as character)
  - How far along that edge (length)

================================================================================
                          ANIMATION SEQUENCE
================================================================================

For input "banana", the animation shows 7 steps (6 chars + $ terminator):

Step 0: Add 'b'
┌───┐
│ R │──[b$]──┐0│
└───┘        └─┘

Step 1: Add 'a'
┌───┐
│ R │──[b$]──┐0│
└─┬─┘        └─┘
  │
  └──[a$]──┐1│
           └─┘

Step 2: Add 'n'
┌───┐
│ R │──[b$]───┐0│
└─┬─┘         └─┘
  ├──[a$]───┐1│
  │          └─┘
  └──[na$]──┐2│
            └─┘

Step 3-5: Add 'a', 'n', 'a'
(Active length increases, waiting for rule 3 or split)

Step 6: Add '$' (terminator)
(Final step - all implicit suffixes become explicit)

Full tree with all suffixes represented:
- banana$
- anana$
- nana$
- ana$
- na$
- a$
- $

================================================================================
                         INTERACTION EXAMPLES
================================================================================

MANUAL STEPPING (Learning Mode):
1. Start application
2. Enter "banana"
3. Press RIGHT arrow repeatedly
4. Watch each character get added
5. Observe how nodes split and edges form
6. Press LEFT to go back and review

AUTO PLAY (Demo Mode):
1. Start application  
2. Enter "mississippi"
3. Press SPACE to start animation
4. Watch automatic construction
5. Press SPACE to pause at interesting points
6. Press R to reset and try again

TESTING MODE (No GUI):
1. Run: make test
2. Observe test output showing node counts
3. Verify correct behavior for multiple inputs
4. No graphics needed - runs in terminal

================================================================================
                           COLOR SCHEME
================================================================================

In the actual SFML GUI, you'll see:

- Background: Light gray (240, 240, 240)
- Nodes: Blue circles (100, 150, 255)
- Active Node: Red circle (255, 100, 100)
- Edges: Dark gray lines (50, 50, 50)
- Text: Black for readability
- Status: Red when paused, Green when playing
- Node Outlines: Black borders

================================================================================
                         SYSTEM REQUIREMENTS
================================================================================

Minimum:
- C++11 compatible compiler
- SFML 2.5 or later
- OpenGL capable graphics
- 1024x768 display resolution

Recommended:
- Modern C++ compiler (GCC 7+, Clang 5+)
- SFML 2.6
- 1920x1080 display for comfortable viewing
- Keyboard for controls

================================================================================
                            GETTING STARTED
================================================================================

1. Install SFML:
   Ubuntu/Debian: sudo apt-get install libsfml-dev
   macOS: brew install sfml
   
2. Build:
   make

3. Run:
   ./SuffixTreeAnimation

4. Try examples:
   - "abc" (simple)
   - "banana" (classic example)
   - "aaa" (repeated characters)
   - "mississippi" (complex patterns)
